A quick guide

  1. Import the agent’s spreadsheet. Include an original page URL and the claims to check in each row.
  2. Open the original page. Compare it with each claim and add an optional note.
  3. Make the call. Choose incorrect, inconclusive, or correct. You can revisit or clear any decision.
  4. Export your reviews. Download the original data with review status, notes, and timestamps. Reimport it to continue elsewhere.

Each queue has its own page size and page controls. Only one queue opens at a time. Inconclusive counts as reviewed, but is never counted as accepted.
